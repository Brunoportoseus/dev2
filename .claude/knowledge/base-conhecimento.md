# Base de Conhecimento — Squad de Análise de Dados

> **Como usar este arquivo**
> Preencha as seções abaixo com o contexto dos seus projetos pessoais e
> análises. Todos os agentes da squad leem este arquivo automaticamente antes
> de iniciar qualquer análise. Quanto mais preciso e atualizado, melhores e
> mais contextualizadas serão as respostas. Apague os exemplos entre `[ ]`.
